# D-01. Pila tecnológica y alcance funcional

**Estado:** Vigente

## Decisión

Python 3.12, FastAPI, Pydantic 2, SQLAlchemy 2 con psycopg 3, Alembic. Interfaz en React, TypeScript, Vite y una biblioteca de componentes accesible (se elige en T13). Orquestación con LangGraph 1.x y checkpointer en PostgreSQL. PostgreSQL 16 o superior con pgvector (HNSW) y búsqueda de texto (`tsvector`, configuración `simple`); cola de trabajos en PostgreSQL con `SELECT ... FOR UPDATE SKIP LOCKED`. Embeddings bge-m3 (1 024 dimensiones) y reranking bge-reranker-v2-m3, locales en CPU y servidos por un servicio de modelos compartido. Docling, GROBID y python-docx para el procesamiento documental. Crossref, doi.org, Unpaywall y OpenAlex (con clave) para servicios bibliográficos. Los requisitos RF-18 a RF-27 quedan aceptados.
